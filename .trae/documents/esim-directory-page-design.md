# 页面设计文档（Desktop-first）

## 全局设计规范
### Layout
- 桌面端：内容最大宽度 1200px，左右留白自适应；主要区块使用 CSS Grid（12列）+ Flex 组合。
- 响应式：
  - ≥1200：12列；
  - 768–1199：8列；
  - <768：单列堆叠，筛选抽屉式。

### Meta Information（全站）
- 默认 Title 模板：`{页面主标题} | Global eSIM Directory`
- 默认 Description：突出“按国家查找/对比eSIM套餐”。
- Open Graph：`og:title/og:description/og:type=website/og:image`（来自国家页头图或供应商Logo兜底）。

### Global Styles / Tokens
- 背景：#FFFFFF；文本：#111827；次级文本：#6B7280；分割线：#E5E7EB
- 主色：#2563EB；强调：#F59E0B；成功：#10B981；危险：#EF4444
- 字体：系统字体栈；标题层级：H1 32px/H2 24px/H3 18px；正文 14–16px
- 按钮：Primary（蓝底白字，hover加深）；Secondary（描边）；Link（下划线hover）
- 卡片：圆角 12px，阴影轻量；列表默认“可点击整卡”。

## 页面：首页/目录页（/）
### Meta
- Title：全球 eSIM 目录：按国家查找与对比
- Description：浏览各国家/地区 eSIM 供应商与套餐，支持筛选与跳转购买。

### Page Structure
- 顶部导航（粘性） + Hero 搜索区 + 筛选/结果双栏 + 页脚。
- 桌面端双栏：左侧筛选（300px 固定），右侧结果列表（自适应）。

### Sections & Components
1. 顶部导航
   - 左：Logo（回到首页）
   - 中：主导航（国家、供应商、更新说明/免责声明入口）
   - 右：后台入口（仅展示为“管理后台”链接，不做公开强引导）
2. Hero 搜索区
   - 主标题 + 简短副标题
   - 搜索框：国家/供应商关键词；回车触发
   - 热门国家快捷入口（Chip）
3. 筛选面板
   - 国家选择（下拉/可搜索）
   - 套餐筛选：天数、流量档、是否热点、网络制式、价格区间
   - 排序：推荐/价格/更新时间
   - “重置筛选”与“应用”按钮（移动端抽屉底部固定）
4. 结果列表
   - 结果统计与更新时间提示
   - 卡片内容：供应商Logo、名称、典型套餐摘要（流量/天数/价格）、标签（5G/热点/无限）、“查看详情”
   - 空状态：提示调整筛选；提供热门国家链接
5. 页脚
   - 免责声明、数据来源说明、联系邮箱

## 页面：国家落地页（/country/[slug]）
### Meta
- Title：{国家} eSIM 套餐与供应商对比
- Description：{国家} 旅行/本地上网可用的 eSIM 供应商与套餐筛选、常见问题。
- Canonical：/country/{slug}

### Page Structure
- 面包屑 + 国家头图区 + 内容与列表组合（上文下表）。

### Sections & Components
1. 面包屑
   - 首页 > 国家
2. 国家头图区
   - H1：{国家} eSIM
   - 摘要：适用场景（旅行/商务/长期）与提示（设备需支持eSIM）
3. SEO内容区（可由后台编辑）
   - H2/H3 结构化段落（如何选择、运营商覆盖、激活方式等）
   - FAQ 折叠组件（用于长内容收纳）
4. 推荐与列表
   - 推荐供应商（Top 3 卡片）
   - 套餐表格/卡片列表：显示关键规格；支持同页排序筛选
   - 每行提供“查看详情”与“去购买”入口（去购买打开新窗口并提示外链）

## 页面：供应商/套餐详情页（/provider/[slug]）
### Meta
- Title：{供应商} eSIM 套餐与覆盖国家
- Description：展示 {供应商} 套餐规格、价格、热点/5G支持与购买链接。
- Canonical：/provider/{slug}

### Page Structure
- 顶部信息卡（供应商） + Tabs（套餐/覆盖国家/说明） + 右侧CTA栏（桌面端）。

### Sections & Components
1. 供应商信息卡
   - Logo、名称、官网链接、支持渠道、更新时间
2. 套餐列表（默认Tab）
   - 套餐卡：流量/天数/是否无限/热点/网络制式/价格
   - “去购买”主CTA：强调外链性质（附UTM）
3. 覆盖国家（Tab）
   - 国家列表/搜索（用于长列表）
4. 说明与限制（Tab）
   - eKYC要求、激活方式、退款规则、速度/限速说明（如有）
5. 信任与合规
   - 免责声明：价格可能变化；本站非销售方

## 页面：后台内容管理台（/admin*）
### Meta
- Title：内容管理台
- Description：管理供应商、套餐、国家SEO页与发布。

### Page Structure
- 左侧侧边栏导航 + 右侧主工作区（表格/表单）。

### Sections & Components
1. 侧边栏
   - 概览、国家、供应商、套餐、SEO内容块、媒体库、审计
2. 列表页（国家/供应商/套餐通用）
   - 表格：名称、slug、状态、更新时间、操作
   - 快捷筛选：状态（草稿/已发布/已下线）
3. 编辑页（通用编辑器）
   - 基础字段（名称、slug、状态）
   - 业务字段（价格/规格/覆盖国家/外链）
   - SEO字段（title/description/canonical/noindex/FAQ JSON）
   - 预览按钮（在新标签打开预览URL，草稿仅后台可见）
   - 发布动作条：保存草稿/提交发布/下线
4. 媒体库
   - 上传、替换、删除；显示引用关系（被哪些内容使用）
5. 审计记录
   - 时间线列表：编辑人、动作、摘要、回滚入口
